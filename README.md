# 🐍 Snake Tail

A classic Snake Game built using **Python** and the **Turtle Graphics** module.

This project was developed as part of my learning journey through Instructor Angela Yu's *100 Days of Code: The Complete Python Pro Bootcamp* on Udemy. I also added a few features to make the game more interactive.

## Features

- Classic snake movement using arrow keys.
- Food generation at random positions.
- Score tracking and high score display.
- Persistent high score using file handling.
- Collision detection with walls and the snake's tail.
- Welcome screen with game instructions.
- Restart functionality after Game Over.

## Technologies Used

- Python
- Turtle Graphics
- Object-Oriented Programming (OOP)

## How to Play

| Key        | Action |
|----|-----|
| Arrow Keys | Move the snake |
|----|----|
| Space      | Start the game |

| R          | Restart the game |

| Q          | Quit the game |

**Objective:** Control the snake, collect food, increase your score and avoid hitting the walls or your own tail!

## How to Run

1. Make sure Python is installed on your system.
2. Clone this repository:

```bash
git clone https://github.com/ShrutiRao13/Snake-Tail.git
```

3. Navigate to the project folder:

```bash
cd Snake-Tail
```

4. Run the game:

```bash
py main.py
```
